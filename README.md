# 苏大学士 · 每个人心中都有个苏东坡

以苏东坡为叙事的公益文化站点：生平、名家点评、作品精赏、高考作文素材库与人生对标。
纯静态站（HTML/CSS/JS 零构建），GitHub Pages 托管。

## 栏目

| 页面 | 内容 |
|---|---|
| `index.html` | 首页：苏东坡立像全屏开场 |
| `shengping.html` | 生平 · 年表与贬谪足迹线 |
| `mingjia.html` | 名家谈东坡（林语堂、余秋雨、王国维、林清玄等，引文注明出处） |
| `zuopin.html` | 作品精赏（原文逐字校对，附题解与赏析） |
| `gaokao.html` | 高考作文素材库（写作 SOP + 六大主题素材卡） |
| `rensheng.html` | 人生对标（青年学才、中年学旷、老年学淡） |

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

推送到本仓库 `main` 分支即自动由 GitHub Pages 发布（Settings → Pages → Source: main / root）。
