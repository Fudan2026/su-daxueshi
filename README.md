# 苏大学士 · 每个人心中都有个苏东坡

以苏东坡为叙事的公益文化站点：生平、名家点评、作品精赏、高考作文素材库与人生对标。
纯静态站（HTML/CSS/JS 零构建），GitHub Pages 托管。

## 栏目

| 页面 | 内容 |
|---|---|
| `index.html` | 首页：苏东坡立像全屏开场 |
| `shengping.html` | 生平 · 年表、贬谪足迹线、乌台诗案始末 |
| `mingjia.html` | 名家谈东坡（10 家，引文注明出处） |
| `zuopin.html` | 作品精赏（18 篇，原文逐字校对，附题解与赏析） |
| `renwu.html` | 东坡人事（亲友、政敌、知己，八张人物卡） |
| `shenghuo.html` | 人间东坡 · 生活志（美食、书画、趣闻公案） |
| `shuhua.html` | 翰墨丹青 · 书画志（寒食帖流转史、存世真迹藏地、书论、绘画） |
| `minjian.html` | 巷陌东坡 · 民间志（民间故事、情缘轶闻、辨伪坊，逐条标注可信度） |
| `jinju.html` | 金句库（八主题 60+ 句，全部注明出处） |
| `gaokao.html` | 高考作文素材库（写作 SOP + 主题素材卡 + 真题适配表） |
| `rensheng.html` | 人生对标（青年学才、中年学旷、老年学淡） |
| `search.html` | 站内检索（普通检索免费 + 高级检索会员门控） |

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

推送到本仓库 `main` 分支即自动由 GitHub Pages 发布（Settings → Pages → Source: main / root）。
